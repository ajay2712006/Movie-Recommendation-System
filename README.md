# Basic-Movie-Recommendation-System
## 🚀 Live Demo
You can check out the live version of the Movie Recommendation System here:
[View Live App](https://movie-recommendatorapp.streamlit.app/)

steps to live the project :-

1. Verify requirements.txt: Make sure all your dependencies (like streamlit, pandas, scikit-learn, etc.) are listed inside the file.
2. Go to share.streamlit.io and log in with your GitHub account.
3. Click "New app".
4. Set the fields:
5. Repository: ajay2712006/Movie-Recommendation-System
6. Branch: main
7. Main file path: app.py
8. Click "Deploy!". Within 1–2 minutes, you will get a live public URL.
